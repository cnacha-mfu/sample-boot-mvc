# sample-boot-mvc — Spring MVC with Thymeleaf demo

In-class live-coding demo: server-rendered pages with `@Controller` and
Thymeleaf — `th:each` lists, `th:object`/`th:field` forms, `@ModelAttribute`
save with POST-redirect-GET, `@PathVariable` delete, and MockMvc tests.
